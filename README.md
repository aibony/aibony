**Design principles:**
- **SSOT (Single Source of Truth):** Every environment variable, import chain, and symbol wiring is audited before any sync operation proceeds
- **OODA Loop:** Observe → Orient → Decide → Act, running asynchronously and continuously
- **Hardware-constrained by design:** Built on 2 GB VRAM — constraint as architecture discipline, not limitation
- **Governed autonomy:** Autonomy without accountability is a defect, not a feature
